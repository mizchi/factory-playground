# 同じシナリオで、最後を誰が決めたか

実際に Pi でGMと2人のPCを動かし、Codex に試遊編集を任せた例。下に結末を掲載している。自分で遊ぶなら、先にGMだけが[シナリオ](examples/moon/draft-1/scenario.json)を読む。

## 最初に映画館で見つかったこと

「閉館する海辺の映画館で、誰の思い出をどう残すかを遊び手が決める」という卓を生成した。両PCが「また遊びたい」と答えた初稿で、編集者は改稿を求めた。手紙の宛名も文面も映さず封をする音だけを残す、という配達人の働きかけは効いた。一方、最後に三つの記憶を短くつないで上映すると決めたのはGMだった。エンドロールの一行は空白にできていても、作者が約束した編集権は卓に渡っていなかった。

## 月面図書館で試したこと

依頼は「月面図書館の閉館前夜、消えかけた貸出票の謎を二人で解きたい。犯人探しより、最後に誰に何を貸すかを自分たちで決めたい」。初回の結末は「閉館の鐘が鳴り、最後の一冊と、借り手の名を待つ光だけが二人の前に残った」。司書はこのままでは再試遊を望まず、返却人は別の結末を求めて再試遊を望んだ。改稿後も自動判定は未達だった。

最初の稿を固定し、同じ2人・同じ「残り時間が半分になる」カードで、GMの最終描写の前に明示的な決断の手番を置いて再試遊した。

| ログ | 起きたこと |
|---|---|
| S0 | 消えかけた貸出票に「借り手：まだ記憶を持たない者」とある。 |
| D1 | GMは、返却人が自身の記憶を一つ失って地球へ運ぶ案と、司書が館外に出られなくなる代わりに本を守る案を提示。第三案も歓迎した。 |
| A2.1 / A2.2 | 司書は未来の子を借り手に選んだ。返却人は二人で本を読み上げて地球に送る案を出した。 |
| S2 | 宛名は「閉館後、地球で最初に生まれる読者」。読み上げた記憶が地球へ送られ、二人は代償を支払った。 |

「未来の読者」は最初の手がかりから予想できた。両PCは再試遊を望み、編集者の判定は `READY_FOR_HUMAN`。ただし、なぜ借り手を一人に絞る必要があるかの手がかりは薄い、という指摘が残った。GMの発話も毎回変わるので、この1組の比較から手番追加の効果量は出せない。人の卓では「第三案を歓迎した瞬間に、本当に自分で別案を考えたくなったか」を聞きたい。[卓の公開ログ](examples/moon/draft-1/session.json)・[事前予想](examples/moon/draft-1/predictions.json)・[各PCの感想](examples/moon/draft-1/survey.json)・[引用付き講評](examples/moon/draft-1/assessment.json)

この見本はモデルを呼ばずに読める。別の初見卓で同じシナリオを試す場合は、リポジトリのルートで次を実行する。1は同じカード、0は揺らぎなし。

```sh
just trpg-replay templates/trpg/examples/moon/draft-1 1
```
