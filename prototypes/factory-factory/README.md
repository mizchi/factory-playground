# Factory Factory

未開拓の惑星に母工場を1基着陸させ、現地資源だけで子工場を増やしながら地表を緑化する Three.js のシミュレーター。観察する範囲は惑星上の18 × 18区画。

## 試遊

リポジトリのルートから起動する。Node.js 24以上、pnpm、just、WebGL 2対応ブラウザーを使う。

```sh
pnpm --dir prototypes/factory-factory install --frozen-lockfile
just factory-factory
```

表示されたURLを開くと **班を配置** で始まる。工場を地図か配置先メニューで選び、鉱石採掘・採氷・子工場の建設・緑化の枠を押す。最初は3班。たとえば母工場の鉱石採掘・採氷・建設に1班ずつ置くと、シード7では1手目に着工できる。同じ枠をもう一度押すと班を回収できる。

- 1枠に1班を置ける。各工場では割り当てる作業の電力合計が日照を超えない。青い印は配置した班で、地表の淡い青は配置先の作業範囲。
- **5日進める** と、稼働中の工場は割り当てられた仕事を5日間行う。着工済みの工場は進捗し、手の終わりに班は戻る。稼働工場が1基増えるごとに次の手から1班増え、上限は8班。
- 8手（40日）で稼働4基・緑化8区画を目指す。シード7の試遊では、前半4手を採掘と建設、後半4手を採氷と緑化に使って、稼働4基・緑化11区画に到達した。

**自動運転** に切り替えると、方針に沿って稼働するサンドボックスを別に進められる。**実行** で連続運転し、**+1 日** で過程を追える。どちらのモードでも、**鉱石**・**氷**では明るい区画ほど埋蔵量が多く、区画をクリックすると地質や工場の在庫を調べられる。地形シードを替えて **再着陸** すると、表示中のモードを別の地形で始められる。

地図では鉱石採掘が橙、採氷が水色、着工が琥珀、稼働開始がシアン、緑化が緑のエフェクトで表示される。系譜ラインの光は親工場から子工場へ流れる。端末で視差効果を減らす設定を有効にすると、静止した色分けで状態を確認できる。

## 工場が持つ性質

- **現地調達。** 工場ごとに、上下左右の移動距離で2区画以内から有限の鉱石と氷を採掘し、自分の在庫に入れる。範囲が重なる工場は埋蔵量を共有する。在庫の工場間輸送は省略した。
- **発電。** 日照で決まる予算は1基あたり毎日4〜7。鉱石の採掘に2、氷の採掘に1、着工・建設中の作業・緑化に各2を使う。未使用分は翌日に持ち越さない。
- **自己増殖。** 親工場は鉱石20と氷4を支払い、距離3以内の未改変区画を確保する。候補は周辺の残存資源と日照で順位づけし、他の工場から2区画以上離す。子工場は自分の区画の日照で4日かけて稼働し、親と同じ機能で採掘・建設・緑化を始める。
- **環境改変。** 工場の作業範囲で、工場のない区画に氷1と電力2を投じる。5回で緑化完了。緑化は地表の変化を表す指標で、気温・気圧・生態の計算は省略した。
- **方針の切り替え。** 増殖は建材の確保に集中する。両立は採掘・建設後に余った電力と氷を緑化に使う。緑化は新規着工と鉱石採掘を止め、着工済みの工場は完成させる。

地形シードと方針を変えた日が同じなら、結果を再現できる。自動運転では、同じ日数で工場の系譜と緑化区画を比べられる。たとえばシード7では以下のようになる。

| 100日間の運転 | 稼働工場 | 緑化済み区画 |
| --- | ---: | ---: |
| 増殖のみ | 46 | 0 |
| 両立のみ | 33 | 84 |
| 緑化のみ | 1 | 12 |
| 40日間増殖してから緑化 | 20 | 44 |

## 参考にした研究とSF

- Gregory Benford の『Terraforming Ganymede with Robert A. Heinlein』（2011年）では、小惑星帯の鉱床から自己複製する機械群が、指令の変更で増殖を止め、ガニメデを改変する装置の製造へ切り替わる。[Baen掲載の本文](https://www.baen.com/terraformingganymede1)
- Frederik Pohl と Thomas T. Thomas の『Mars Plus』（1994年）では、採掘用の自己複製機械を火星のテラフォーミング向けに転用する構想が登場する。[著者の作品紹介](https://www.thomastthomas.com/SFBooks.htm)・[E. M. Choi による作品分析](https://www.marspapers.org/paper/Choi_2000.pdf)
- NASA / ASEE の研究報告（1982年）は、月面で採掘・製造を自動化し、子工場も複製を続けられる構想を示す。現地資源だけで工場を再生産するには、どの材料と部品を現地で賄えるかが設計課題になる。[Self-replicating lunar factory and demonstration](https://ntrs.nasa.gov/citations/19830007081)
- Metzger ら（2013年）は、小さな初期設備から現地生産を広げる宇宙産業の立ち上げをモデル化した。[Affordable, Rapid Bootstrapping of the Space Industry and Solar System Civilization](https://arxiv.org/abs/1612.03238)
- McKay ら（1991年）は、火星に生存可能な環境をつくるために変えるべき気温・気圧・大気組成などを検討した。惑星改変を今後モデル化する際の出発点になる。[Making Mars Habitable](https://lunar.earth.northwestern.edu/courses/438/mckay1991.pdf)
- Dennis E. Taylor の『We Are Legion (We Are Bob)』は、自己複製するフォン・ノイマン探査機が居住可能な惑星を探す物語。Kim Stanley Robinson の『Red Mars』では、火星をどこまで変えるべきかが入植者の対立になる。[We Are Legion (We Are Bob)](https://www.simonandschuster.com/books/We-Are-Legion-%28We-Are-Bob%29/Dennis-E-Taylor/Bobiverse/9781668221570)・[Red Mars](https://www.penguinrandomhouse.com/books/156201/red-mars-by-kim-stanley-robinson/)

`just factory-factory-test` で世代交代、資源の収支、着工済み案件の完了、再現性、班と電力の制限、増員、作戦期限を検証できる。
