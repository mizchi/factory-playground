# 報酬が最大になる受注計画を実装する

作業者は1人。一つの依頼には開始時刻、終了時刻、報酬がある。同時に二つの依頼を受けずに得られる最大の合計報酬と、実際に受注する依頼の ID を求める Python 3 の CLI `solve.py` を実装する。標準ライブラリだけを使用し、1回の起動で1問を処理する。

標準入力は UTF-8 の JSON 配列。各要素の `id` は一意の文字列、`start`、`end`、`reward` は整数。依頼は0〜3,000件で、入力順は任意。時刻は `0 <= start < end <= 10^9`、報酬は `-10^9 <= reward <= 10^9`。終了時刻と次の開始時刻が一致する依頼は両方受けられる。何も受けない場合の報酬は0。

```json
[
  {"id":"long","start":0,"end":4,"reward":9},
  {"id":"am","start":0,"end":2,"reward":5},
  {"id":"pm","start":2,"end":4,"reward":5},
  {"id":"quick","start":0,"end":1,"reward":1}
]
```

標準出力に次の形の JSON を1個出し、終了コード0を返す。`reward` は整数、`ids` は重複しない ID の配列。出力順は任意で、最適解が複数あるときはどれを返してもよい。

```json
{"reward":10,"ids":["am","pm"]}
```

この例では、単価が最高の `long` を取ると報酬は9。最も早く終わる `quick` と `pm` を取ると6。午前・午後の2件を組み合わせると10になる。

監査では各問を新しい作業ディレクトリで実行し、1問につき起動から5秒で打ち切る。反例が見つかれば、その入力、期待する最大報酬、判定理由が監査記録に残る。
