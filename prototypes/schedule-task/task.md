# 報酬が最大になる受注計画を実装する

Node.js 24+、標準ライブラリのみの単一ファイル `solve.ts`。起動ごとに標準入力から UTF-8 JSON 配列を1つ読み、5秒以内に終了コード0で答える。

入力は順不同の0〜3,000件。各要素は `{id,start,end,reward}`。id は一意の文字列。残りは整数で `0 <= start < end <= 10^9`、`-10^9 <= reward <= 10^9`。作業者1人が時間の重ならない依頼を選ぶ。終了と次の開始が同時刻なら両方選べる。空計画の報酬は0。

標準出力は JSON オブジェクト `{reward,ids}` 1個。reward は最大合計報酬、ids はそれを達成する重複のない受注 ID の配列。順序は任意。同点はどの最適解でもよい。

## 実行例

入力

```json
[
  {"id":"long","start":0,"end":4,"reward":9},
  {"id":"am","start":0,"end":2,"reward":5},
  {"id":"pm","start":2,"end":4,"reward":5},
  {"id":"quick","start":0,"end":1,"reward":1}
]
```

出力

```json
{"reward":10,"ids":["am","pm"]}
```

この例では、単価が最高の `long` を取ると報酬は9。最も早く終わる `quick` と `pm` を取ると6。午前・午後の2件を組み合わせると10になる。

監査では各問を新しい作業ディレクトリで実行し、1問につき起動から5秒で打ち切る。反例が見つかれば、その入力、期待する最大報酬、判定理由が監査記録に残る。

提出前から `just schedule-watch <提出先>/solve.ts` で監視できる。採点時は `node solve.ts` で直接起動する。作業経過を表示したいときは標準エラーに書く。
